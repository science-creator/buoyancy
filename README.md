# 🌊 물체를 떠오르게 하는 힘 실험실

중학교 1학년 과학 「Ⅴ. 힘의 작용」 — **부력**.
학습 목표 **부력의 개념을 알고, 중력과 부력의 크기에 따른 물체의 움직임을 설명할 수 있다.**

## 어떻게 여나

**설치할 것이 없습니다.** `index.html` 을 더블클릭하면 바로 열립니다.

| 화면 | 파일 | 하는 일 |
|---|---|---|
| 🌊 실험실 | `index.html` | 물을 붓고, 부력을 재고, 배에 짐을 실어 본다 |
| 📝 학습지 | `worksheet.html` | 15문항 (12문항 자동 채점) · 종이로도 뽑을 수 있다 |
| 🔑 정답지 | `worksheet.html?key` | 정답만 A4 **한 쪽**. 선생님용 화면에서 들어간다 |
| 🗂️ 선생님용 | `teacher.html` | 제출한 PDF 를 파일 이름만 읽어 정리한다 |

## 무엇을 보여 주나

- **🧪 스타이로폼 구** — 학습지의 탐구 그대로. 물을 부으면 **용수철이 늘어납니다.**
  위쪽으로 힘이 작용한다는 증거예요.
- **⚖️ 부력 재기** — 공기 중과 물속을 나란히 놓습니다.
  **두 눈금이 벌어진 길이가 곧 부력**입니다.
- **🚢 배와 부력** — 짐을 실을수록 더 잠기고, 잠긴 만큼 부력이 커집니다.
  떠 있는 동안 **부력과 중력은 언제나 같습니다.**

## 이 앱이 남기고 싶은 한 문장

> **부력 = 공기 중에서 잰 무게 − 물속에서 잰 무게.**
> 그 크기는 **잠긴 부피**가 정하고, 중력과 견주어 뜰지 가라앉을지가 정해진다.

## 인쇄

학습지를 열고 `Ctrl+P` — **A4 두 쪽**(실제로 인쇄해서 확인했습니다).
